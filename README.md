# ClipDeck

Windows 剪贴板历史工具。绿色便携，单个 exe，免费，无广告。

按一下热键，弹出最近复制过的文本、图片和文件，选一条就粘贴到刚才的输入框里。

## 安装

1. 到 [Releases](https://github.com/Pockoo/ClipDeck/releases) 下载最新版，解压到任意目录。
2. 运行 `ClipDeck.exe`，右下角托盘会出现图标。
3. 在任意程序里复制东西，按 `` Alt+` `` 呼出列表。

系统要求：Windows 10 及以上，64 位。

## 常用快捷键

| 按键 | 作用 |
| --- | --- |
| `` Alt+` `` | 呼出 / 收起列表 |
| `Enter` | 粘贴选中的条目 |
| `Shift+Enter` | 换另一种方式粘贴（纯文本 / 保留格式） |
| `Alt+1` ~ `Alt+9` | 直接粘贴列表前 9 条 |
| `Del` | 删除选中的条目 |
| `Ctrl+T` | 打开时光机，按日历看历史 |
| `Alt+A` | 截图识别文字 |
| `Alt+T` | 快捷翻译 |

热键都可以在设置里改。

## 功能

**记录和查找**

- 记录文本、图片和文件，可按类型分类：全部、文本、图片、视频、音频、文档、文件。
- 显示内容来自哪个程序，搜索时可以用 `@程序名` 过滤。
- 搜索支持空格分词、拼音首字母（输入 `wx` 能找到“微信”）、日期（`date:today`、`date:2026-11`）和正则（`re:`）。
- 收藏、固定到顶部、拖到右上角的星标上直接收藏。
- 时光机：按月历浏览历史，点某一天看当天复制的全部内容。

**粘贴**

- 多选后可以合并成一条文本粘贴，或者依次粘贴，分隔符和顺序可调。
- 右键“转换并粘贴”：大小写、驼峰 / 下划线等命名风格、全角半角、简繁转换、URL / Base64 / HTML 编码、JSON 格式化和压缩、清除链接里的跟踪参数。
- 把文本或图片拖到桌面、文件夹、聊天窗口时，会自动生成 .txt / .png 文件。
- 条目可以固定到桌面，变成一张悬浮便签，重启后还在。

**文本和图片小工具**

- 列表里能直接看出颜色值、时间戳、算式和单位换算的结果。
- 编辑文本，生成二维码，识别图片里的二维码。
- 图片标注和裁剪：矩形、箭头、马赛克，可撤销。
- 图片识别文字（系统自带 OCR，离线），也可以改用 Google Lens。
- 翻译文本（微软 / 必应 / 腾讯）。快捷翻译：在输入框里按热键，输入内容回车，译文直接粘贴回去。
- 截图识别：按热键框选屏幕区域，松手就识别文字。

**隐私**

- 密码管理器等标记为“请勿记录”的内容不会进入历史，也可以自己指定不记录哪些程序。
- 列表里会把密钥、银行卡号、身份证号、`password=` 后面的内容遮住一部分，只影响显示，粘贴出去的还是原内容。
- 托盘菜单里可以暂停记录一段时间。

**外观**

- 跟随系统的浅色 / 深色，毛玻璃，多种配色预设或自定义主题色，圆角和阴影可调。
- 迷你模式：屏幕边缘留一条细线，鼠标碰到就展开最近几条。
- 文字用 GDI 绘制，装了 MacType 也能正常接管。

## 数据放在哪

全部在程序所在目录，不写注册表：

| 文件 | 内容 |
| --- | --- |
| `ClipDeck.ini` | 配置，用文本编辑器就能改 |
| `ClipDeck.db` | 历史记录 |
| `ClipDeckFav.db` | 收藏 |
| `notes\` | 桌面便签 |

历史库和收藏库的位置可以在设置的“存储”页修改。

想卸载：先在托盘菜单取消“开机自启”，退出程序，删除整个目录即可。

## 联网说明

大部分功能都在本地完成。只有这几处会联网：

- 检查更新：每次启动会访问一次 GitHub，看有没有新版本，有的话只在列表底部提示，不会弹窗。
- 翻译：使用翻译功能时，文本会发给所选的翻译服务。
- Google Lens：只有在设置里选了它做识别时，图片才会上传。默认用系统 OCR，不联网。

## 常见问题

**按了热键没反应？**
热键可能被别的程序占用了，到设置里换一个。

**系统 OCR 识别不出文字？**
系统 OCR 需要装对应语言的 OCR 语言包，在 Windows 的“语言和区域”里添加。

**历史库能放到别的盘吗？**
可以，在设置的“存储”页改路径，重启后生效，旧数据不会自动搬过去。
